## 📋 Installation

### Prerequisites
- **Python 3.11+**
- **Windows 10/11**
- **Gemini API Key** (Gemini 2.5 Flash/Pro recommended)
- **MetaTrader 5** (Optional, for native trading)

### Quick Start
```bash
git clone https://github.com/moyesrex-ops/Axiom.git
cd Axiom
pip install -r requirements.txt
python -m playwright install chromium
Axiom.bat
```
